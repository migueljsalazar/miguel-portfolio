# Miguel Portfolio

Planning repository for an original portfolio and brand site that treats the
website as a working creative space.

The current direction combines two ideas:

- the spatial, exploratory portfolio model demonstrated by DORF; and
- the material, collaborative, deliberately slow studio culture documented
  around Deaton Chris Anthony and Studio 75 AV.

The goal is inspiration, not imitation. The final site should use Miguel's own
stories, objects, images, and visual identity.

## Status

Research and implementation planning are complete. The application has not
been scaffolded yet.

- [Research synthesis](docs/RESEARCH.md)
- [Implementation plan](docs/IMPLEMENTATION_PLAN.md)

## Public-repository boundary

This repository currently contains only public-source research, original
analysis, and planning. It does not contain private project details,
credentials, client material, or third-party reference images.

Before portfolio content is committed, every case study and media asset should
be reviewed for confidentiality, attribution, and publication rights.
